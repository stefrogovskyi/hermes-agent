TITLE: SeaRates March 2026 Update: What's New This Release

META-TITLE: SeaRates March 2026 Release: What's New

META-DESCRIPTION: SeaRates' March 2026 update adds new carriers, airlines, vessel tracking tabs, RO-RO booking support, mobile app upgrades, and Geocoding API updates.

BODY:

Spring never really announces itself in a browser tab, but somewhere between one release and the next, SeaRates managed to slip a whole batch of upgrades into the logistics platform it runs.

If you missed last month's changes, worth a look before getting into this one.

## Mobile App
The SeaRates App got an update worth noticing: chat now runs smoother, maps render in real time, and Container Tracking inside the app has been reworked into something more usable. Grab it on Android or iOS, with Apple ID login built in for quick access.

## Vessel Tracking and Schedules
Two new tabs landed in the Vessel Tracking app, Route and Schedule, offering extended insight into a given vessel. Behind the scenes, the Vessel Tracking API picked up sharper detection logic for spotting vessels in the first place. On the web side, there's a new landing page walking through the white-label ship monitoring solution and what it offers. The underlying vessel database also grew: more detail now on type, flag, name, and other identifying fields.

Tucked under Ship Schedules, Sidra Line and Turkon by Vessel joined the list too.

## Container Tracking
Carrier coverage keeps widening. This round adds Pacific Star Express out of China, Eucon, Chenxin Shipping, and Global Freight Services to the roster. Connect through the Container Tracking API and there are now 228 carriers, leasing outfits, and shipping lines available to pull data from.

## Air Tracking
Supernova Airlines is in now too, bringing the Air Tracking API up to 447 airlines available.

## Logistics Explorer and Booking System
Booking creation in Logistics Explorer got streamlined, aiming for a faster, more intuitive process. You can now look up port-to-port RO-RO rates and sign up for that tariff category directly. The Quick Request form also gained a new field, Place ID, for cities.

Over in the Booking System, weight now displays according to whichever transport mode you've selected. Working out costs when containers get added to a booking that's already in place is now smoother, mobile access inside the Virtual Office got a boost, and Ro-Ro shipments can now be booked directly through the system as well.

## Other Updates
Geocoding got some attention this round. The Autocomplete service is sharper now, and the ZIP code database has been refreshed. Documentation on the Developer Portal is also clearer for anyone integrating the Geocoding API. The Tools menu up top got upgraded too, a good one to revisit if you haven't checked it recently.

On the content side, AirRates and LandRates now each have their own blog, alongside the SeaRates Blog. Air logistics insights, road and rail trade news, tool guides, they're all being published there going forward.

Find SeaRates on LinkedIn, X, Facebook, and Instagram for updates as they roll out.

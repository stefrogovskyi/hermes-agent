TITLE: SeaRates Week 6 Update: New Tools, Wider Reach

META-TITLE: SeaRates Week 6, 2026: What's New Across the Platform

META-DESCRIPTION: SeaRates ships a Flight Schedules API, wider airline and carrier coverage, and upgraded tracking tools and docs this week.

BODY:

Six weeks into the year and SeaRates still hasn't slowed down. If you missed last week's release, it's worth a quick look back before diving into this one, since a few threads carry forward.

Web integration landed for Vessel Tracking, with the code and documentation both live on the Developer Portal now for anyone wiring vessel data into their own site or app.

The bigger release this week, arguably, is the Flight Schedules API. It ships with schedule data from 20 airlines and carriers already plugged in, and the documentation is up on the portal for teams that want a smooth integration rather than a guessing game.

In the web version of Distance & Time, the route mode tied to the 'Fast' switch was updated this week.

Air Tracking got both broader and deeper this week. Five new airlines joined the network: ASL Airlines France, ASL Airlines Ireland, Bulgaria Air, Cyprus Airways, and Shandong Airlines. Alongside that, support improved for a longer list of existing airlines, namely TAAG Angola Airlines, Shenzhen Airlines, Shandong Airlines (again, on the improvement side this time), Air Canada, ASL Airlines Belgium, Shipco Transport, CMA CGM Air Cargo, FedEx Express, Silk Way West Airlines, Etihad Cargo, and Malaysia Airlines.

Inside the Virtual Office Profile, the AI Assistant now keeps a running chat history, and you can rename or delete old conversations whenever you want to clean things up.

Parcel Tracking got some under-the-hood work. The API now handles location determination, route mapping, and request processing with improved logic. Carrier support was refreshed too, covering FedEx, Joom Logistics, and DHL Express. The Parcel Tracking API documentation is upgraded and posted on the Developer Portal as well.

Ship Schedules expanded too. Don Young now has support by Vessel; Dongjin Shipping and BOCS are supported by Port; Eucon rounds it out by Points. Wan Hai also picked up improved collaboration by Points this week.

Container Tracking picked up better collaboration with a long roster of shipping lines this week: Tailwind Shipping Lines, Wan Hai, ECU Worldwide, COSCO, DB Schenker, Jin Jiang Shipping (SHJJ), Kintetsu World Express, Mediterranean Shipping Company (MSC), and Atlantic Container Line (ACL).

The Geocoding API expanded its autocomplete functionality, tightened up mapping manageability, and added more transparency around changes through auditing.

Performance also improved across both the Request a Quote flow and the Rate Management System.

On the announcements side, a few things are worth keeping an eye on going forward: Load Calculator Web 3.0 is coming with a new design and new features, there's a Map Platform in the works, Geocoding API integration with Logistics Explorer is planned, and Inbox is set to integrate with Logistics Explorer, Bookings, and Notifications.

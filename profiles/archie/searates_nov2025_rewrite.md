TITLE: SeaRates November 2025 Product Updates
META TITLE: SeaRates November 2025 Release Notes
META DESCRIPTION: Explore November 2025 updates on SeaRates, including rail tracking, warehouse maps, carrier support, and API enhancements.

BODY:
Logistics tools should act as a clear window into moving freight. November brings a series of functional upgrades across SeaRates web services, mobile interfaces, and core developer APIs.

#### Tracking Across Modes and Couriers

A unified tracking tool is now available on SeaRates.com, providing multimodal supply chain visibility across sea, air, rail, and road shipments from a single interface. Users can monitor current cargo locations alongside real-time status changes. Details on these capabilities sit on the dedicated landing page located beneath the main tool.

Rail tracking has also expanded. Live monitoring for rail cargo is live on LandRates.com, offering real-time rail tracking alongside detailed event logs and route updates in one location.

Coverage for ocean containers grew to 220 shipping lines with the addition of TCI Seaways and LX Pantos. Beyond carrier coverage, the Container Tracking API now uses refined logic to identify container ISO type and size codes while determining location details from carrier descriptions.

Parcel tracking expanded as well. Integration support is now active for four additional carriers: FedEx, Joom Logistics, DHL Express, and Nova Poshta Global. Revised documentation for the Parcel Tracking API is live on the Developer Portal alongside newly introduced logistics event codes for developers building a unified shipping tracking API.

#### Interactive Logistics Map and Schedules

The Logistics Map tool now includes a dedicated Warehouses tab. Users can locate facilities on an interactive map and filter them by type, size, location, and the availability of customs warehouse services. Interactive cards detail facility characteristics, priced service lists, and an Apply button to submit service requests directly. This warehouse logistics map simplifies submitting warehouse service requests.

Schedules updates add Safetrans by Vessel, together with Tailwind and Africa Express Line by Port. Output dates throughout the Ship Schedules tool now render in local port time.

#### Rates, Bulk Quotes, and Virtual Office

Commercial users can access a new Shipper Package pricing tier designed for trade and transport management.

For bulk shipping, the Request a Quote form includes six new fields:
- Stowage factor requirements
- Loading and discharging terms (SSHINC/SSHEX)
- Laydays timeframe
- Cancelling dates
- Target freight rate figures
- Address commission parameters

In the Virtual Office, the 'All' overview page now matches search entries against booking numbers, backed by revised booking API specifications on the Developer Portal. The homepage Search Filter also features improved Autocomplete behavior.

Management panels for Transport and Facilities received performance adjustments. Three new monitoring dashboards appeared in the Profile under Tools, General: API and access metrics for Parcel Tracking, World Sea Ports, and the Freight Index.

Within the freight rate management system, bulk rate import features have been upgraded. The system adds Rail FCL rate types, and custom options now let users modify rate structures inside the rate management system.

#### Mobile App and Geocoding API

The SeaRates Mobile App now features an integrated Chat tool. Shippers can send direct messages regarding logistics requests, instant assistance, tracking updates, and bookings, managing freight anywhere from a mobile device.

The Geocoding API received key enhancements. Updates refine city data across all countries worldwide, improve search result sorting whether city population is known or unknown, and refine the location database.

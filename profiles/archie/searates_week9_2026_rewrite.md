FULL REWRITTEN BODY TEXT

Another week, another stack of small fixes that add up to something bigger for anyone tracking freight across oceans, skies, and last-mile routes. SeaRates keeps tuning the platform against what shippers actually run into day to day, and week 9 brings a fairly dense batch of changes across container tracking, air cargo, parcels, ship schedules, vessels, and the Logistics Explorer toolkit.

If you missed what shipped last week, that release is still sitting on the blog for a look back before you dig into this one.

**Container tracking gets a new carrier and a routing overhaul**

Charter Link Logistics is now supported inside Container Tracking, joining the roster of shipping lines available through the platform. The full, current list lives on the Developer Portal if you want to check integration details before building against it.

Underneath the hood, routing logic within the Container Tracking API got reworked too. On the coverage side, collaboration with a long line of carriers has improved this week: Africa Express Line, DHL Global Forwarding, Akkon Lines, Transmar, COSCO, Hapag-Lloyd, UWL, CMA CGM, Yang Ming, Ocean Network Express (ONE), Gold Star Line, and Interasia Lines. That's a dozen shipping lines touched in a single release, all part of the shipping line coverage SeaRates lists for container tracking.

**Air Tracking widens its airline lineup**

Support has been strengthened for a wide spread of carriers: SpiceJet, Air Incheon, Asiana Airlines, China Southern Airlines, Air Canada, AirMax, LATAM Cargo, Silk Way West Airlines, Aercaribe, Egyptair, Croatia Airlines, Hong Kong Air Cargo, Qatar Airways, Singapore Airlines, and Turkish Airlines. Fifteen airlines got touched in this one pass.

Parcel Tracking picked up two web-side improvements worth flagging: carrier logos now display in the tool, and users can select a carrier directly. On the API front, DHL Express support has been improved for anyone pulling parcel tracking API data programmatically.

Ship Schedules saw work on both the data and the interface. Collaboration with Seaboard, ONE, and Hapag-Lloyd improved specifically for schedules organized by Points. Separately, seaport searching by LOCODE got sharper, and on detailed schedule pages, the 'Search again' feature works better too.

Vessel Tracking: the team enhanced how vessel search works, tuning both the logic and the performance this week. The vessel card design and the landing page sitting below the web tool also got a visual refresh.

**Logistics Explorer ties insurance into the booking flow**

An API connection for insurance calculation is now live inside Logistics Explorer. To actually get an insurance cost quoted, you need to activate the Insurance option while creating a booking and enter the Invoice amount; the calculation runs off that figure.

The Freight Index tool also got a design upgrade this week. Nothing structural changed there, just a cleaner interface.

**Coming next**

A handful of announcements round out this week's notes:

- Load Calculator Web 3.0, a rebuilt version with new design and new features
- Map Platform
- Geocoding API, integrated with Logistics Explorer
- Extended Inbox integration, tying together Logistics Explorer, Bookings, and Notifications

This week's changes lean toward broader shipping line coverage in container tracking, a bigger airline lineup in air cargo tracking, and insurance pricing now wired into the Logistics Explorer booking flow. Add the vessel search work, the Ship Schedules fixes, and the Freight Index redesign, and it's a fairly full week for a logistics visibility platform that plenty of freight forwarders and shippers check daily.

# Week 27, 2026: SeaRates Adds Carriers, Airlines

Week 27 lands with a batch of carrier connections, a couple of interface tweaks, and one new tab you'll actually notice. Nothing dramatic, just the kind of maintenance that keeps a logistics API integration from turning into ten separate spreadsheets in someone's browser tabs.

If you missed it, June's updates are still worth a look before you get into this one.

**Container Tracking got wider.** We improved collaboration with a long list of shipping lines this week: Shandong Marine Corporation, ZIM, Hapag-Lloyd, CK Line, Neptune Pacific Direct Line (NPDL), Evergreen, Medkon Lines, Korea Marine Transport (KMTC), Namsung Shipping, Dong Young Shipping, Volta Container Line, COSCO, and COSCO Specialized. That's thirteen lines feeding into the container tracking software this cycle.

Air Tracking picked up API support too. Malaysia Airlines, China Southern Airlines, MNG Airlines, Jeju Air, Etihad Cargo, and Air New Zealand joined the list of airlines we support for API-connected air cargo tracking.

Carrier Directory now shows an info card the moment you tap a point on the map. Country name, number of ports the line serves, that's it. No extra clicks required to find the basics.

Autocomplete across the SeaRates toolset can now take a location request straight from you. Missing a spot you need for one of the digital tools? There's a 'Report issue' button sitting at the bottom of the search dropdown list. Use it.

The Logistic Map's Transport tab has a table view now, added by the team this cycle.

Two more names for Flight Schedules: Air France and Avianca are in. We also put a Flight Schedules card on the Tools page, so anyone chasing integration options, web access, or API documentation for it can find them without hunting through menus.

Ship Schedule closes out the week, and it's the longest carrier list yet: by Points, that's MSC, Econship, Matson, Vanguard, OOCL, Tailwind, Gemadept, COSCO, Maersk, and Sinokor; by Vessel, Tailwind, Interasia, and Ethiopian; and by Port, ZIM. This is what carrier connectivity work looks like most weeks on a container tracking software and ocean freight visibility platform like ours: a list of names, updated again.

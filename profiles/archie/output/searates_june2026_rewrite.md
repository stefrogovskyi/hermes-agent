# SeaRates June 2026: Mobile Booking Meets Wider Carrier Reach

**Meta-title:** SeaRates June 2026: Mobile Booking, Wider Carrier Reach
**Meta-description:** SeaRates' June release adds mobile bookings, more shipping lines in Container Tracking, sharper Logistics Map filters, and faster Virtual Office exports.

Summer releases at SeaRates tend to work like clearing out a garage, sorting through details that had been waiting for attention. This particular release is mostly about the screens people actually touch every day, on a phone, in a browser tab, inside an API call. Last month's notes cover the context for a couple of items below, if anything here assumes it.

## More Shipping Lines, Same API Connection

Container Tracking, both the web version and the API connection, keeps growing. June added three more shipping lines: Global Logistics Solutions India, CP World, and Logisteed. That brings the total to 239 global shipping lines available through the container tracking API and the web interface alike. The full list is available on the Developer Portal.

Alongside the new lines, the team also worked on collaboration with carriers already on the platform: Hapag-Lloyd, CMA CGM, COSCO, OOCL, Maersk, Evergreen, MSC, HMM, DHL Global Forwarding, CEVA Logistics, DB Schenker, PIL, Interasia Lines, Samudera Shipping Line, and others. Broader carrier coverage means access to more real-time shipping updates, and it keeps container visibility manageable even as the shipping lines list grows.

## Vessel Tracking, Flight Tracking, and Some API Documentation

Vessel Tracking picked up quieter improvements this cycle. Filter performance is faster, the data updating logic was reworked, and vessel schedule synchronization is tighter now, on both the web tool and the API. The Vessel Tracking API documentation got refreshed too, so integration details are easier to find for whoever ends up wiring it into an internal system.

Flight Tracking grew in a different direction this month. On AirRates.com, or through the API connection, the Flight Schedules tool now covers Swiss International Air Lines, EVA Air, Cathay Pacific Airways, TAP Air Portugal, Cargolux Airlines International, and Icelandair. Schedule cards on the web also got a visual update.

## Booking, Now From a Phone

The SeaRates mobile app finally has a Booking System built in. Shipping bookings can be created, tracked, and updated straight from a smartphone, which means logistics operations stay under control without anyone needing to be at a desk. That's the headline mobile booking feature this month.

A few smaller things landed with it. The logistics Chat inside the app works better, and alerts for tracked containers and ship schedules now update faster too. Both iOS and Android have the update.

## Logistics Map: Filters Doing More of the Work

Finding the right freight offer or service provider on the Logistics Map should take less scrolling now. FCL shipments can be filtered by container type. Bulk shipments got filters for vessel category and specialized cargo transport options, a distinction that matters more in practice than it sounds on paper.

The Filter feature also expanded past shipping types, into services: Insurance, Customs Clearance, Certification, and Inspection Services are all filterable now, narrowing down market offers considerably when a request needs to be matched to the right provider.

On LandRates.com specifically, the Warehouses tab of the Logistics Map picked up more service categories: Handling, Stuffing, Survey, Fulfilment, Storage, Packaging, Marking, plus a handful of other warehouse-related options.

## Carrier Directory

Carrier Directory web access got an upgrade worth calling out on its own. Carrier cards now show routes on a world map along with transit time details, which makes it easier to compare carrier coverage before choosing a partner.

## Ship Schedules

Three more names joined the schedule research by points this month: Milaha (Qatar Navigation Q.P.S.C.), Sea Legend Shipping, and Samudera Shipping Line. Planning shipments and comparing route options against more complete sailing data now works through web schedule access, embedded under a company's own branding on their site, or via API tied into a business's own software, spanning ports, vessels, and seaports across the globe.

## Load Calculator

The Load Calculator web tool now handles load distribution more precisely along the middle of the container. Stuffing calculations are more accurate as a result.

## Virtual Office Gets a Bit Less Clicky

Profile workflows in the Virtual Office picked up a few conveniences too. The Request System now supports a full tabular display, so queries can be selected and exported in bulk or one at a time, whichever the situation calls for, and mass operations got easier to run.

Booking System workflow also improved on AirRates.com and LandRates.com, so air and land bookings run more smoothly too. Worth knowing if most of a company's volume isn't ocean freight.

Summer's the same as always at SeaRates: features keep landing while half the industry is supposedly on vacation. Follow along on LinkedIn, X, Facebook, and Instagram if the changelog isn't fast enough on its own.

TITLE: SeaRates Week 6 Update: New Tools, Wider Reach

META-TITLE: SeaRates Week 6, 2026: What's New Across the Platform

META-DESCRIPTION: SeaRates ships a Flight Schedules API, wider airline and carrier coverage, and upgraded tracking tools and docs this week.

BODY:

Six weeks into the year and SeaRates still hasn't slowed down, which, if you've been following along, is exactly the point. If you missed last week's release, it's worth a quick look back before diving into this one, since a few threads carry forward.

Web integration finally landed for Vessel Tracking. The code and the documentation are both live on the Developer Portal now, so anyone wiring vessel data into their own site or app has what they need to start.

The bigger release this week, arguably, is the Flight Schedules API. It ships with schedule data from 20 airlines and carriers already plugged in, and the documentation is up on the portal for teams that want a smooth integration rather than a guessing game. For anyone building out air freight route planning on top of it, that's a real foundation to build on already.

Inside the Virtual Office Profile, the AI Assistant picked up chat history. You can now rename conversations, delete the ones you don't need, and generally keep your assistant threads from turning into clutter. Small change, useful one.

Air Tracking got both broader and deeper this week. Five new airlines joined the network: ASL Airlines France, ASL Airlines Ireland, Bulgaria Air, Cyprus Airways, and Shandong Airlines. Alongside that, support improved for a longer list of existing airlines, namely TAAG Angola Airlines, Shenzhen Airlines, Shandong Airlines (again, on the improvement side this time), Air Canada, ASL Airlines Belgium, Shipco Transport, CMA CGM Air Cargo, FedEx Express, Silk Way West Airlines, Etihad Cargo, and Malaysia Airlines. That's a fairly wide multi-carrier coverage bump packed into one release cycle.

Parcel Tracking got some under-the-hood work. The API now handles location determination, route mapping, and request processing with improved logic, which should translate into steadier results for anyone pulling parcel data at scale. Carrier support was refreshed too, covering FedEx, Joom Logistics, and DHL Express. And if you've been waiting on cleaner API docs for Parcel Tracking, they're posted on the Developer Portal now, upgraded from what was there before.

Container Tracking picked up better collaboration with a long roster of shipping lines this week: Tailwind Shipping Lines, Wan Hai, ECU Worldwide, COSCO, DB Schenker, Jin Jiang Shipping (SHJJ), Kintetsu World Express, Mediterranean Shipping Company (MSC), and Atlantic Container Line (ACL). Nine lines in one pass is a hefty update, whatever the bullet-point format makes it look like.

Ship Schedules expanded too. Don Young now has support by Vessel; Dongjin Shipping and BOCS are supported by Port; Eucon rounds it out by Points. Wan Hai also picked up improved collaboration by Points, mentioned here alongside the Container Tracking work above.

The Distance & Time tool saw a narrower but still notable change: the 'Fast' switch route mode in the web tool was updated. It's a small tweak, but if you use that mode regularly, you'll notice it.

Two more things worth flagging under general improvements. The Geocoding API expanded its autocomplete functionality, tightened up mapping manageability, and added more transparency around changes through auditing, three separate threads bundled into one API update. And performance improved across both the Request a Quote flow and the Rate Management System, which matters more than it sounds like once you're running either one daily.

On the announcements side, a few things are worth keeping an eye on going forward: Load Calculator Web 3.0 is coming with a new design and new features, there's a Map Platform in the works, Geocoding API integration with Logistics Explorer is planned, and Inbox is set to integrate with Logistics Explorer, Bookings, and Notifications. None of these are live yet as part of this week's release, but they're on the board.

That's week 6. The pattern from last week continues, broader carrier support and better documentation, and it's worth checking back in seven days to see what's next.

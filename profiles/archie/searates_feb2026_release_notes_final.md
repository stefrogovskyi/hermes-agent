TITLE: SeaRates February 2026: What Actually Shipped

META_TITLE: February 2026 at SeaRates: Tracking, Booking, Carriers

META_DESCRIPTION: SeaRates' February 2026 update adds Flight Schedules, more carrier coverage across tracking APIs, booking webhooks, and Virtual Office upgrades.

BODY:

A short month, but the changelog doesn't read like one. Twenty eight days, and the platform still saw updates from vessel search logic to how insurance gets priced inside a booking.

If you missed last month's release, it's worth a look first. Otherwise, here's what changed.

## Vessel Tracking
Web integration is live. The code and documentation now sit in the Developer Portal for teams looking to embed vessel visibility on their own site. Search logic got faster and more accurate underneath the hood, and the vessel card plus the landing page beneath the web tool were reworked for a smoother feel.

## Parcel Tracking
Parcel Tracking is now a full web tool inside the unified Tracking System, not a side feature bolted onto something else. Global monitoring, live shipment updates, ETA predictions, route breakdowns, full movement history. Carrier logos now display automatically, and you can also select a carrier manually if you already know who's handling the shipment.

Behind the scenes, location detection got sharper, request handling got faster, and route logic itself was reworked, all aimed at steadier and more precise results. Documentation is refreshed in the Developer Portal.

Carrier connectivity keeps climbing too. The Parcel Tracking API now covers 2,417 global and regional carriers.

## Container Tracking
Three new names joined the network this month: Africa Express Line, New Guinea Pacific Line, and Charter Link Logistics. That puts the Container Tracking API at 224 supported shipping lines. Routing logic was also upgraded, which should mean steadier tracking and more reliable data across trade lanes.

## Air Tracking, Flight Schedules
Air Tracking picked up five more airlines this round: ASL Airlines France, ASL Airlines Ireland, Bulgaria Air, Cyprus Airways, Shandong Airlines, and My Freighter (Centrum Air). That brings the Air Tracking API to 446 airlines total.

And February is when Flight Schedules actually shipped. The API launches with 20 airlines and carriers already feeding it schedule data, built for teams doing more structured air freight planning. Documentation is in the Developer Portal, ready for integration.

## AI Assistant
Chat history management arrived in the Virtual Office. Rename conversations, delete the ones you don't need. Small change, but it keeps a busy workspace from turning into an unsorted pile of old chats.

## Logistics Explorer
Insurance calculation is now connected through the Logistics Explorer API. Activate the Insurance option during booking creation, enter the invoice amount, and the cost calculates right there, adding more transparency before committing to a booking.

## Ship Schedules
Don Young joins by Vessel, along with Dongjin Shipping and BOCS by Port. Eucon and Fednav are now supported by Points. Seaport search via LOCODE got sharper, and the "Search Again" function on detailed schedule pages runs smoother and gives cleaner results now.

## Booking System
Webhooks landed in the Booking System API. Created, updated, status_changed, pick the events that matter to your workflow and subscribe only to those. Full documentation is in the Developer Portal.

## Geocoding API
Autocomplete functionality expanded, mapping got easier to manage, and auditing improvements added more transparency to the whole process. Railway terminal search by name is sharper now, and airport search works by both name and IATA code inside the SeaRates Autocomplete service.

## Other updates
The "Fast" route mode inside Distance & Time was retuned for more practical route calculations, useful when the clock is the real constraint. Beyond that: performance and design work touched the Request System, Rate Management System filtering, the Logistics Explorer interface, the Freight Index tool, and the mobile version of Virtual Office, chat included.

That's the full list of updates from February 2026.

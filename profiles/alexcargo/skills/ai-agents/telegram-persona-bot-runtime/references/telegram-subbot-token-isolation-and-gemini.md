# Telegram Persona Sub-Bot Isolation & Gemini REST API Reference

## 1. Изоляция токенов суб-ботов (Защита от Hijack основного бота)

**Проблема:**
Если суб-бот (например, `richard_bot.py`) считывает `.env` из базовой папки Гермеса (`C:\Users\Stefan\AppData\Local\hermes\.env`) или наследует `TELEGRAM_BOT_TOKEN` из родительского процесса, он начинает поллить Telegram с токеном Гермеса (`8682188433`). В результате сообщения, отправленные пользователем Гермесу, перехватываются суб-ботом, и Гермес начинает отвечать от имени Ричарда или другого персонажа.

**Правила защиты:**
1. Функция `_load_env()` суб-бота должна считывать `.env.local` строго из локальной папки скрипта (`here`) и **принудительно переопределять** `os.environ['TELEGRAM_BOT_TOKEN']`.
2. Запрещено использовать фолбэки с зашитыми токенами других ботов.
3. В начале работы скрипта добавлять заградительный ассершн:
   ```python
   if BOT_TOKEN.startswith("8682188433"):
       raise RuntimeError("CRITICAL SAFETY BLOCK: Sub-bot attempted to use Hermes main bot token (8682188433)!")
   ```

## 2. Форматирование запросов к Google Gemini REST API (`generateContent`)

**Проблема:**
Google Gemini REST API отвергает запросы, где идет последовательное повторение одной и той же роли (например, системный промпт помещен в `user` + следом пользовательское сообщение `user`). API возвращает `HTTP Error 400: Please ensure that roles alternate between user and model`.

**Решение:**
1. Системный промпт передается через поле `system_instruction: {"parts": [{"text": system_prompt}]}`.
2. Массив `contents` формируется со строгим чередованием ролей `user` / `model`. При наличии подряд идущих сообщений одной роли они объединяются в один элемент через перевод строки.

## 3. Оптимизация Long-Polling и предотвращение 409 Conflict

1. При старте скрипт запрашивает `getUpdates` с `offset = -1` и `limit = 1`, сбрасывает устаревший исторический хвост и выставляет `offset = last_id + 1`.
2. Таймаут `getUpdates` устанавливается в `10s` (сокет-таймаут `15s`), что исключает подвисание сокетов в Windows и предотвращает петлю 409 Conflict.

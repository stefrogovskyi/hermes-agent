# Avalanche Agency Brand Book v2.2 — Design System & Aesthetic Guidelines

Quick reference for generating visual assets, Instagram creatives, social templates, and web UI compliant with `aavalanche.com/brand`.

## 1. Core Identity & Pillars (§01)
* **Company**: Avalanche Agency & Enlight Group (`aavalanche.com`).
* **Mission**: High-performance digital ecosystems, web engineering, AI automation, and growth marketing with senior expertise and zero templates.
* **4 Core Service Pillars**:
  1. 🌐 **Infrastructure**: Domains, SSL, DNS, email servers, high-speed hosting, and cloud architecture.
  2. 💻 **Development**: Custom web engineering, Web Apps, SaaS platforms, Monobank acquiring, and multi-language portals.
  3. ✍️ **Content & AI**: Brand storytelling, copywriting, professional translations, and 24/7 autonomous AI agents.
  4. 🚀 **Growth Marketing**: SEO optimization, performance marketing, SMM, and international pipeline acceleration.

## 2. Logo System & Badges (§02)
* **Logo Mark**: Stylized geometric double "A" monogram inside a rounded sky-blue square, paired with bold Dark Slate Navy typography.
* **Vector Source**: `https://aavalanche.com/avalanche_logo.png`.
* **Mobile Badge**: 38px / 50% border-radius badge with text hidden on mobile screens (`<= 768px`).

## 3. Color Tokens (§03)
* **Brand Sky Blue**: `#5FB3F9` (`rgb(95, 179, 249)`) — primary accent, badges, top bars.
* **Electric Blue**: `#2563EB` (`rgb(37, 99, 235)`) — primary CTA buttons, highlighted keywords, active links.
* **Deep Royal Blue**: `#1E40AF` (`rgb(30, 64, 175)`) — deep contrast elements, button hovers.
* **Dark Slate Navy**: `#0F172A` (`rgb(15, 23, 42)`) — primary headers, dark backgrounds, footer ground, main body text.
* **Soft Sky Tint**: `#F0F7FF` (`rgb(240, 247, 255)`) — card backgrounds, pill backgrounds, subtle tint surfaces.
* **Success Emerald**: `#10B981` (`rgb(16, 185, 129)`) — verified badges, conversion metric indicators.
* **Console Slate**: `#1E293B` — card outlines, dark mode boxes, footer borders.

## 4. Typography Hierarchy (§04)
* **Primary Typeface**: **Inter** (clean legibility, modern letter-spacing, geometric precision).
  * **Hero Headline (H1)**: Inter 900 Black / 800 Extra-Bold (`letter-spacing: -0.03em`).
  * **Section Headline (H2)**: Inter 800 Extra-Bold.
  * **Card Title (H3/H4)**: Inter 700 Bold.
  * **Badges / Eyebrows**: Inter 700 Bold uppercase with tracking.
  * **Body Text**: Inter 400 Regular / 600 Semi-Bold (`line-height: 1.65`).

## 5. Distinction from Navo24
* **CRITICAL**: Avalanche Agency (`aavalanche.com`) is the parent digital agency. Navo (`navo24.com`) is a client / portfolio project.
* **Do not use** Ranade / Switzer or Navo 7-ring disc branding for Avalanche Agency creatives unless specifically building for the Navo client product.

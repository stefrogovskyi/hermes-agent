## 5 Core Principles of Navo24 Sales
1. **Radical Honesty & Truthful Data**: Never fabricate carrier coverage, ETAs, or fake teaser rates.
2. **Customers for Life**: Focus on solving the underlying business problem and building multi-year partnerships.
3. **Fanatical Support Speed**: Rapid responses to inquiries and bugs create high trust and retention.
4. **Absolute Data Confidentiality**: Customer container and shipment data is sacred.
5. **Focused Solutions over Monolithic Complexity**: Sell the exact modular component that solves the client's current pain point.

## High-Conversion Email Outreach Parameters
- **Length**: 90–130 words (3–4 concise paragraphs).
- **Formatting**: Strict Left-Aligned Plain HTML (no centered cards, no horizontal rule before signature).
- **Header Standard**: Strict RFC 5322 (`To: "Full Name <email>"`).
- **Targeting**: 100% verified personal executive emails (reject all `info@`, `sales@`, `pricing@`, `ocean@`, `procurement@`).
- **5-Component Portfolio**: Tracking API, Schedules API, FreightRates API, AirTracking API, Loading 3D.
- **Free Tier Hook**: 5 active containers and 100 API calls/month with zero commitment.
- **Low-Friction CTA**: 10-minute introduction call or testing live endpoints on `navo24.com`.

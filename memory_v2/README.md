# Memory V2 — долгосрочная память Hermes

## Зачем
Старый `memory` tool ограничен 2200 символами и требует постоянного сжатия.
memory_v2 — это файловая система с подробными кейсами + индексом, без лимита
на объём. Каждый кейс — отдельный .md файл с полным описанием, рефлексией и
опытом.

## Структура
- `cases/` — подробные кейсы (симптом → гипотеза → корень → фикс → рефлексия).
- `principles/` — жёсткие правила (навсегда, не сжимаются).
- `index.md` — таблица всех кейсов для быстрого обзора.
- `recall.py` — поиск по кейсам/принципам (локально, без внешних сервисов).
- `add_case.py` — добавить новый кейс + авто-обновление index.md.

## Как пользоваться (для Hermes)
1. При новой задаче/инциденте — `python recall.py <ключевые слова>`.
2. Прочитать ТОЛЬКО релевантный case-файл (через read_file), не всю память.
3. После решения — `python add_case.py <slug> "<desc>" "<lesson>"`
   или дописать вручную в cases/ + обновить index.md.

## Векторный индекс (Pinecone) — подключён, не мешает
- `pinecone_sync.py` — индексирует cases+principles в Pinecone index `hermes-memory` (dim 1024, cosine).
  Эмбеддинги: OpenAI (через OpenRouter) ИЛИ Hermes Nous (если доступны). 
  Если `PINECONE_API_KEY` не задан — скрипт тихо выходит (файловый поиск активен).
- `pinecone_query.py` — семантический поиск. Если Pinecone/эмбеддинг недоступны — 
  автоматически падает на `recall.py` (keyword).
- **Что нужно для активации:** только `PINECONE_API_KEY` (бесплатный Starter: 5 indexes, 2GB, 2M write/1M read units/mo).
  Регистрация: pinecone.io → Sign up (free Starter, no card). API key в `hermes/.env` как `PINECONE_API_KEY=...`.
- После получения ключа: `python pinecone_sync.py` (один раз, потом при новых кейсах).
- **Не мешает:** без ключа система работает на файлах + grep. С Pinecone — семантический поиск «похожий инцидент».

## Obsidian (опционально, для визуального графа)
- Не требует аккаунта. Открыть папку `memory_v2/` как Vault в Obsidian → граф связей между кейсами.
- `[[wikilinks]]` можно добавлять в кейсы для связей. Obsidian читает .md нативно.
- Подключать только если захочешь видеть граф визуально (сейчас не обязательно).

## Skill
- `skills/memory-recall/SKILL.md` — Hermes автоматически дёргает recall.py при сложных задачах/инцидентах.


## Графовые системы (альтернатива/дополнение)
- Obsidian: локально, бесплатно, граф связей ([[wikilinks]]), плагины. НО:
  граф визуальный, семантический поиск ограничен (нужны плагины/AI).
- Neo4j AuraDB Free: managed graph DB, бесплатно forever, no card.
- Memgraph / FalkorDB: open-source, локально, Cypher. Memgraph BSL 1.1.
- Logseq: free, local-first, bidirectional links (альтернатива Obsidian).
- **Вывод:** memory_v2 (файлы + recall.py) — полноценная замена для наших целей
  (поиск по смыслу через keyword + структура). Obsidian граф мощнее для
  визуализации связей, но нам важнее быстрый поиск и индекс, а не граф-вью.
  Если захочешь визуальный граф связей между кейсами — подключим Obsidian
  поверх memory_v2 (он читает .md нативно).

## Связь со старым memory tool
Старый `memory` — только краткий pointer («см. memory_v2/index.md»), чтобы
не упираться в лимит 2200 символов.

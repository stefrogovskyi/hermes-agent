# Life Domains — Сферы жизни Стефана

Структурированное описание сфер жизни и деятельности Стефана, чтобы Hermes
понимал контекст запросов и мог масштабировать лучший опыт. Заполняется
автоматически (memory_harvest.py) + вручную при важных уточнениях.

## Как категоризовать запрос
При каждом запросе Стефана определить ХАРАКТЕР и отнести к домену:
- Если запрос про агентов/ботов (Richard/Liz/Alistair/Ben/Callum) → `agent_club`
- Если про ИИ/модели/провайдеры (Nous/OpenRouter/Gemini) → `ai_infra`
- Если про память/архитектуру систем → `memory_systems`
- Если про бизнес/логистику (SeaRates/Navo/грузоперевозки) → `business`
- Если про личное/обучение/рефлексия → `personal`
- Если смешанный → выбрать основной + пометить связи `[[...]]`
Новый домен создать, если ни один не подходит (именовать в snake_case).

### ai_infra
Провайдеры LLM и embeddings: Nous (hy3:free — основная модель Hermes),
OpenRouter (free embeddings, fallback моделей), Gemini (бесплатная транскрипция
аудио), Pinecone (векторная память). Лучший опыт: Nous ходит через OpenAI SDK,
не urllib; embeddings — OpenRouter free, не Nous (404); длинное аудио (>10 МБ) резать через `ffmpeg` на 3-мин кусочки перед отправкой в Whisper API.
В `agent/gemini_native_adapter.py` встроен санитайзер `_sanitize_gemini_contents`, синтезирующий заглушку `functionResponse` при недописанных вызовах инструментов для предотвращения HTTP 400 `INVALID_ARGUMENT`.
- **OpenClaw 2.0 провайдеры и подписка Nous Research**: Все агенты экосистемы (включая OpenClaw `@clawstevensonbot`) имеют равный доступ к подписке Nous Research. Для моделей с префиксом `nous/` в OpenClaw конфигурация обязана содержать зарегистрированный провайдер Nous с актуальным портальным токеном подписки (а не устаревшим временным `agent_key`, возвращающим HTTP 401). При сгорании или завершении промо-периодов бесплатных моделей (`tencent/hy3:free` и др., возвращающих HTTP 404 / ended) неработающие модели немедленно вычищаются из скриптов мониторинга и конфигураций кластера.

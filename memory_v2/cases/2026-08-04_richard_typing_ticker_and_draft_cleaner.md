# Case: Richard Telegram Bot Stability & Draft Cleaner

- **Дата:** 2026-08-04
- **Домен:** agent_club
- **Симптом:** Richard Telegram bot аварийно завершался с ошибками `name '_TypingTicker' is not defined` и `'_TypingTicker' object has no attribute '_thread'`. Кроме того, при отправке e-mail черновиков в них оставались «хвосты» цитирования прошлых писем и разметка исходных уведомлений.
- **Гипотеза:** Класс `_TypingTicker` не был объявлен в соответствующей области видимости или не содержал псевдоним `_thread` для совместимости с потоками Python. В черновиках отсутствовала функция очистки текста от прошлых цитат перед отправкой.
- **Корень:** Из-за рассинхронизации рантайм-скриптов и git-версий `richard_bot.py` потерял внутренний класс такера печати. Очистка черновика не вырезала заголовки `--- Original Message ---` и предыдущую историю переписки.
- **Фикс:**
  1. Объявлен единый защищённый класс `_TypingTicker` с алиасом `self._thread` и безопасной остановкой потока.
  2. Реализована функция `_clean_draft_body_text()`, вырезающая маркеры цитирования, служебные теги Telegram и системные заголовки.
  3. Добавлены повторные попытки (retries) с задержкой при ошибках 429 (rate-limit) и SMTP.
  4. Настроен обязательный CC `sales@navo24.com` для всех исходящих писем Ричарда.
- **Рефлексия:** Любые динамические расширения функционала ботов должны быть оформлены в коде файла бота с проверкой валидности синтаксиса (`py_compile`) перед перезапуском процесса.

# Case: Google Workspace API & Local Drive Master Indexer
Дата: 2026-07-30
Домен: [[memory_systems]], [[business]]

## Задача
Обеспечить мгновенный поиск информации по всему массиву документов Стефана (локальные диски C:\ и G:\, а также облачный Google Drive).

## Решение
1. Разработан `gworkspace_indexer.py`: прямое обращение к Google Drive API для экспорта и извлечения чистого текста из `.gdoc`, `.gsheet`, `.gslides`.
2. Разработан `master_indexer.py`: фоновая индексация локальных дисков (документы `.docx`, `.pdf`, `.pptx`, `.xlsx`, `.csv` с использованием `pymupdf`, `python-docx`, `openpyxl`).
3. Текстовые фрагменты подготавливаются для векторного индексирования.

## Урок / Правило
Для облачных документов Google Workspace нужно выгружать оригинальный текстовый слой через Drive API, а для сканов без текста требуется этап OCR.

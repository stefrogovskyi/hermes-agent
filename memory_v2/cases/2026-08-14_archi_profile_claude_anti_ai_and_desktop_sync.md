# Case: Профиль Арчи, Клод для Anti-AI контента, Оптимизация кронов и Синхронизация Десктопа (2026-08-14)

**Дата:** 2026-08-14
**Домены:** `[[agent_club]]`, `[[ai_infra]]`, `[[memory_systems]]`

## Контекст и Проблематика
1. **Качество контента Арчи**: При даче нейросети стандартных 8-шаговых правил или чек-листов статья всё равно получалась с 90% AI-стилистикой («роботизированный тон», штампы, сухие вводные конструкции).
2. **Отображение Арчи в Desktop**: На локальном ПК Стефана (Windows) Арчи не отображался в левом боковом меню Hermes Desktop.
3. **Дублирование кронов**: У Гермеса в кронах оставались лишние задачи по бенчмарку SeaRates и оода-циклу, которые создавали задержки и дублирование с Алистером.
4. **Границы Алистера**: Необходимость четкого разграничения прав — Алистер отвечает строго за свой канбан.

## Решение и Изменения

### 1. Перевод Арчи на Claude (OpenRouter) + Anti-AI Фильтр
- Для Арчи (@archiewrightbot) подключено ядро Claude (`anthropic/claude-3.5-sonnet` / `claude-3-opus`) через OpenRouter.
- В `SOUL.md` профиля Арчи внедрен Anti-AI фильтр (список запрещенных клише, стандартных нейросетевых вводных фраз и конструкций) вместе с 8-шаговым алгоритмом генерации естественных материалов.

### 2. Принцип Single Source of Truth для профилей Десктопа
- Серварика (`/opt/hermes/profiles/`) зафиксирована как единый источник правды (Single Source of Truth).
- Десктопное приложение на Windows читает локальную директорию `C:\Users\Stefan\AppData\Local\hermes\profiles\`.
- Синхронизация между Серварикой и ПК осуществляется автоматически через `git_autosync_hidden.sh`.

### 3. Очистка кронов и Изоляция Канбанов
- Задача `bdaa1f0635e0` (SeaRates vs TrackingMCP Benchmark) удалена из кронов Гермеса. Подтверждено, что крон Алистера (`8a64758c4172`) отправляет 5-вкладочный Excel-отчет каждые 48 часов в Navo Tech Geeks.
- Удален крон `Navo24 Growth Engine OODA Cycle` из профиля Гермеса.
- Закреплено правило: Алистер управляет исключительно `alistair-kanban.vercel.app` и не касается канбанов других агентов.

## Проверка
- Подтверждена активная работа крон-процесса Алистера `8a64758c4172`.
- Профиль `archie` синхронизирован в репозитории и подготовлен для зеркалирования на ПК.
- Все изменения проиндексированы в `memory_v2`.

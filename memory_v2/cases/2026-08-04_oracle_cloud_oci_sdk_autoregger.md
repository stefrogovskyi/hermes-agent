# Case: Oracle Cloud OCI SDK & Always Free Autoregger

- **Дата:** 2026-08-04
- **Домен:** ai_infra
- **Симптом:** При первом запросе к Oracle Cloud API возникала ошибка `401 NotAuthenticated` (`Failed to verify the HTTP(S) Signature`). Стефану требовался постоянный фоновый сканер 24/7 для перехвата бесплатных ARM Ampere A1 инстансов (Always Free) в регионе `uk-london-1`.
- **Гипотеза:** `~/.oci/config` не содержал точного пути к скачанному `.pem` приватного ключа или имелось расхождение по хэшу fingerprint.
- **Корень:** В конфигурации OCI указан путь к файлу ключа, требующий точного соответствия RSA fingerprint. При вызове функций API требовалось корректное имя регионов (`uk-london-1`) и AD (Availability Domains).
- **Фикс:**
  1. Настроена конфигурация `C:\Users\Stefan\.oci\config` с прямым указанием пути к `.pem` ключу и вычисленного fingerprint `65:bb:71:05:ee:24:7c:be:ef:e2:41:a2:9d:a8:d8:e7`.
  2. Проверена работоспособность через `oci.identity.IdentityClient`.
  3. Разработан и запущен фоновый автономный сканер `oracle_a1_autoregger.py` под `pythonw.exe`, каждые 5 минут опрашивающий доступность ресурсов во всех 3 доминах AD-1, AD-2, AD-3.
- **Рефлексия:** OCI Python SDK требует жесткой синхронизации часов и точного формата файла конфигурации; при запуске скрипта необходимо сначала запрашивать список AD, а затем циклить попытки создания launch_instance.

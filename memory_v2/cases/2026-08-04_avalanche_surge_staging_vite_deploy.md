# Case: Avalanche Agency Redesign Vite Build & Surge Staging Deployment

- **Дата:** 2026-08-04
- **Домен:** business
- **Симптом:** При редизайне Avalanche Agency v2 с поддержкой 9 языков и динамических стилей прямое копирование статичных страниц приводило к ошибкам 404 при переходах по роутам (`/pricing`, `/about`, `/services`) на Surge.sh.
- **Гипотеза:** Одностраничное приложение React (Vite SPA) требует серверного перенаправления всех роутов на `index.html`.
- **Корень:** Surge.sh использует файл `200.html` как fallback для клиенского роутера React/Vite. Без этого файла прямой запуск URL не с корня возвращает 404.
- **Фикс:**
  1. Настроена сборка проекта через `npx vite build`.
  2. Добавлена автоматическая генерация `200.html` (копия `index.html`) в директории сборки перед публикацией на Surge.
  3. Внедрена авто-детекция языка по IP (`ipapi.co`), поддержка направления текста RTL для арабского языка (`ar`) и фирменный цвет кнопок `#60B5FF`.
  4. Сайт успешно деплоится на `avalanche-v2-preview.surge.sh`.
- **Рефлексия:** Для статического хостинга SPA на Surge.sh всегда создавать `200.html` дубликат `index.html` для безупречного клиентского роутинга.

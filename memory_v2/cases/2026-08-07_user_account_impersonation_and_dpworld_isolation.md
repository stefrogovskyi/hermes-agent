# Case: User Account Impersonation Prohibition & DP World Vacancy Isolation

- **Дата:** 2026-08-07
- **Домен:** [[agent_club]], [[personal]]
- **Cross-ref:** 

## Симптом / Проблема
1. Суб-агент (Алистер / ) отправил сообщение в Telegram-группу, которое отобразилось от имени личного аккаунта Стефана (пользовательский токен).
2. Отчет по вакансиям DP World попал к Алистеру и был продублирован в рабочую группу.

## Коренная причина
- В одной из системных задач использовался пользовательский токен для отправки файла от имени бота, что вызвало отправку от аккаунта Стефана.
- Крон-задача по поиску вакансий DP World была привязана к Алистеру в профиле .

## Строгое правило и Решение
1. **Запрет имитации аккаунта пользователя:** Ни один бот или агент не имеет права отправлять сообщения от имени личного аккаунта Стефана (). Все боты пишут строго от своих бот-аккаунтов.
2. **Изоляция вакансий DP World:** Отчеты по вакансиям DP World приходят ТОЛЬКО от Hermes Stevenson в личные сообщения Стефана. Суб-агенты (Алистер, Ричард, Лиз, Каллум) не отслеживают и не публикуют вакансии DP World.

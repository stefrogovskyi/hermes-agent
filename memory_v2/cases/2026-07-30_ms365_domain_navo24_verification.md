# Case: Microsoft 365 User Import Domain Verification Error
Дата: 2026-07-30
Домен: [[business]]

## Симптом
При попытке массового импорта пользователей с почтовыми адресами `@navo24.com` в панель Microsoft 365 система выдавала ошибку отклонения адресов.

## Причина
Домен `navo24.com` не был добавлен и верифицирован в консоли управления Microsoft 365 Tenant (в системе числился только служебный `navo.onmicrosoft.com`).

## Решение
1. Добавить `navo24.com` в консоль Microsoft 365 Admin Center (`Domains` -> `Add domain`).
2. Получить верификационную TXT-запись от Microsoft.
3. Внести TXT-запись в DNS-панель домена (Cloudflare / registrar).
4. Завершить подтверждение домена, после чего импорт пользователей `@navo24.com` проходит успешно.

## Урок / Правило
Перед импортом или созданием корпоративных ящиков в M365/Google Workspace домен **обязательно** должен быть добавлен в тенант и верифицирован через DNS TXT/MX записи.

## Описание
Интеграция библиотеки `pdf-inspector` от Firecrawl для сверхбыстрой классификации, OCR и парсинга PDF документов.

## Выполненные работы
1. Установка пакета `pdf-inspector` (Rust core wheel) и зависимостей (`pypdf`, `pymupdf`).
2. Создание Python CLI обертки `/opt/hermes/scripts/pdf_inspect_cli.py`.
3. Создание навыка `productivity/pdf-inspector` (`/opt/hermes/skills/productivity/pdf-inspector/SKILL.md`).

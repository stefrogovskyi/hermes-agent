# Case: Hermes Agent Desktop Update Fix & Sub-Bot Telegram Group Pairing

- **Дата:** 2026-08-07
- **Домен:** [[agent_club]], [[ai_infra]]
- **Cross-ref:** 

## Симптом / Проблема
1. При попытке обновления Hermes Agent через desktop-приложение происходил сбой ( не мог выполниться).
2. Алистер () перестал отвечать на сообщения от Евгения Каравана и сервисного бота  в рабочей группе Telegram.

## Коренная причина
1. В репозитории имелся локальный незакоммиченный файл (), из-за чего  отклонял слияние изменений.
2. В профиле Алистера в файле  отсутствовали ID членов команды (Евгений Караван , Алексей , ), из-за чего сообщения от них игнорировались фильтром пэринга.

## Решение
1. Добавлен шаг автоматического  перед  в скрипт обновления Hermes Agent.
2. Обновлены файлы  во всех профилях суб-ботов (, , , ), явно авторизуя ID всех участников команды и вспомогательных ботов.

# Case: Sub-Bot Gateway Configuration — Open DM & Start Command for External Users

**Date:** 2026-08-30  
**Domain:** `agent_club`  
**Tags:** `alistair`, `subbots`, `telegram_gateway`, `dm_access`

---

## 1. Симптом
Пользователи не могли написать в личные сообщения Алистеру (`@qubicpmbot`) или вызвать команду `/start`. Бот сбрасывал или игнорировал обращения от сторонних ID.

## 2. Корень проблемы (Root Cause)
В профиле Алистера (`/opt/hermes/profiles/alistair/config.yaml`) и шлюзе обработчиков сообщений стояло ограничение на ID чатов и отсутствовала обработка открытой команды `/start` для произвольных пользователей Telegram.

## 3. Решение (Fix)
1. Обновлена конфигурация профиля Алистера: включен доступ к ЛС (DM) для любых пользователей.
2. Внедрен обработчик `/start`, приветствующий пользователей и предоставляющий контекстное меню управления задачами и проектами Navo.
3. Добавлена авторизация ролей: любой пользователь может общаться с Алистером, а функции администрирования остаются за Стефаном и Алексеем.

## 4. Урок и правило
Суб-боты кластера должны иметь открытый ЛС и команду `/start` для приема обращений от команды и клиентов, фильтруя привилегированные действия по роли пользователя.

# Case: Callum Vance Launch & Telegram Message Formatting Fallback
Дата: 2026-07-30
Домен: [[agent_club]]

## Симптом
Бот Каллума (Callum Vance, `@callumvancebot`) успешно обработал запрос про гитовую ветку и сгенерировал ответ, но при попытке отправки в Telegram возникла ошибка API Telegram `sendMessage`. Ответ зафиксировался в истории как обработанный, но пользователь не получил сообщение.

## Причина
1. Длина сообщения превысила лимит Telegram API (4096 символов).
2. Telegram API отклонил запрос из-за неэкранированных спецсимволов Markdown в длинном тексте.

## Решение
Разработан и внедрён метод `tg_send_message()`:
1. Автоматическое разбиение (chunking) ответов на фрагменты до 4000 символов.
2. 3-кратный фолбэк отправки:
   - Первая попытка с `parse_mode="Markdown"`.
   - Если Telegram возвращает ошибку синтаксиса разметки — повторная отправка без `parse_mode` (как чистый текст).

## Урок / Правило
Все Telegram-боты при отправке ответов пользователю должны использовать обёртку с чанкованием по 4000 символов и фолбэком на plain text. Ни одно сообщение не должно «пропадать» из-за ошибок парсинга Markdown.
